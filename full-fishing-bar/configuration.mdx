Full Fishing Bar exposes five settings that let you dial in exactly how much the mod assists your fishing. You can change every setting either by editing the config file directly or through the in-game Generic Mod Config Menu (GMCM) UI — no restart required when using GMCM.

## Config File Location

The config file is generated automatically the first time you launch the game with the mod installed:

```
Stardew Valley/Mods/FullFishingBar/config.json
```

If you prefer the in-game UI, open the pause menu, select **Mod Settings**, and choose **Full Fishing Bar**. Changes made through GMCM are saved and take effect immediately without a restart.

<Note>
  If GMCM is not installed, you must edit `config.json` manually and restart the game for changes to take effect. GMCM is free, optional, and available on [Nexus Mods](https://www.nexusmods.com/stardewvalley/mods/5098).
</Note>

## Settings Reference

### General

<ParamField body="IsEnabled" type="bool" default="true">
  The master on/off switch for all mod functionality. Set this to `false` to disable Full Fishing Bar entirely without uninstalling the mod — the bobber bar returns to its vanilla size and auto-hook stops firing. Flip it back to `true` to restore all configured behaviour.
</ParamField>

### Customizations

<ParamField body="BarSizePercentageInt" type="int" default="100">
  The bobber bar height as a percentage of the full fishing track. The mod clamps this value to the range **10–100**.

  | Value | Effect |
  |-------|--------|
  | `100` | Bar fills the entire track — catching any fish is trivial |
  | `75`  | Bar covers three-quarters of the track — comfortable but not automatic |
  | `50`  | Bar covers half the track — noticeably easier than vanilla |
  | `10`  | Minimum value — a small boost, close to vanilla difficulty |

  Adjust this in GMCM using the slider, which displays values as percentages (e.g. `75%`).
</ParamField>

<ParamField body="OnlyCorkBobber" type="bool" default="false">
  When set to `true`, bar resizing only activates if a **Cork Bobber** is attached to your fishing rod. With no Cork Bobber equipped, the mini-game runs at vanilla difficulty regardless of `BarSizePercentageInt`.

  This turns the Cork Bobber from a minor quality-of-life item into a meaningful, intentional choice: equip it when you want easier fishing, leave it off when you want the challenge.
</ParamField>

<ParamField body="ExceptBossFish" type="bool" default="false">
  When set to `true`, the mod skips bar resizing for boss fish encounters. Boss fish are the legendary and story-critical catches with their distinctive green progress bar — they remain at full vanilla difficulty even while all other fish benefit from the larger bar.

  Use this setting if you want the accessibility benefits of a larger bar day-to-day but still want boss fish to feel like genuine milestone catches.
</ParamField>

<ParamField body="AutoHook" type="bool" default="false">
  When set to `true`, the mod automatically triggers the hook the moment a fish nibbles on your line — you never need to watch the screen and click (or press a button) in time. If you're using a controller, a short rumble pulse fires as tactile confirmation.

  Auto-Hook does not activate if your rod already has the **Auto-Hook enchantment** applied at the Forge, since the enchantment handles the same behaviour at the game level.
</ParamField>

## Example config.json

```json
{
  "IsEnabled": true,
  "OnlyCorkBobber": false,
  "BarSizePercentageInt": 100,
  "ExceptBossFish": false,
  "AutoHook": false
}
```

This is the default configuration. All features are active, the bar fills the entire track, and auto-hook is off.

## Balanced Configuration

<Tip>
  For a more rewarding middle-ground, try combining `OnlyCorkBobber: true` and `ExceptBossFish: true` with a `BarSizePercentageInt` somewhere around `60`–`75`. This setup makes the Cork Bobber feel like a genuinely useful tool you choose to equip rather than a passive bonus — ordinary fishing becomes easier when you want it to be, boss fish remain challenging and memorable, and the mini-game still requires some attention on normal catches. It preserves the satisfying structure of fishing without the most frustrating failure cases.
</Tip>
