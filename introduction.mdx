Hedgehog Technologies builds focused, quality-of-life mods for Stardew Valley that tackle specific pain points without overcomplicating your game. The four mods in this collection each solve a distinct problem — from automating repetitive tasks like foraging and inventory cleanup to removing platform limitations and mini-game friction. Every mod is built on SMAPI, the Stardew Modding API, and requires **Stardew Valley 1.6 or later**.

<Note>
  All four mods require [SMAPI](https://smapi.io) to run. Install SMAPI before downloading any mod in this collection. See the [Installation guide](/installation) for step-by-step instructions.
</Note>

## The Mods

<CardGroup cols={2}>
  <Card title="Auto Forager" icon="leaf" href="/auto-forager/overview">
    **Problem it solves:** Manually shaking every bush and tree you pass is slow and easy to forget.

    Auto Forager automatically shakes bushes, fruit trees, and other forageable plants as your character walks near them. You control exactly which plant types trigger collection, and the mod supports content packs for modded forageables.

    Download: [Nexus Mods](https://www.nexusmods.com/stardewvalley/mods/7736) · [CurseForge](https://www.curseforge.com/stardewvalley/mods/auto-forager)
  </Card>
  <Card title="Auto Trasher" icon="trash" href="/auto-trasher/overview">
    **Problem it solves:** Inventory clutter from unwanted items breaks your flow and wastes time.

    Auto Trasher discards items on your customizable trash list the moment they enter your inventory. A built-in reclaim system lets you recover anything sent away by mistake, so you never lose something important.

    Download: [Nexus Mods](https://www.nexusmods.com/stardewvalley/mods/23663) · [CurseForge](https://www.curseforge.com/stardewvalley/mods/auto-trasher)
  </Card>
  <Card title="Allow Beach Sprinklers" icon="droplet" href="/allow-beach-sprinklers/overview">
    **Problem it solves:** The Beach Farm layout blocks sprinklers from working, forcing you to water crops by hand.

    Allow Beach Sprinklers removes that restriction so every sprinkler type functions on the Beach Farm exactly as it does on any other farm layout. No configuration needed — just install it.

    Download: [Nexus Mods](https://www.nexusmods.com/stardewvalley/mods/7629) · [CurseForge](https://www.curseforge.com/stardewvalley/mods/allow-beach-sprinklers)
  </Card>
  <Card title="Full Fishing Bar" icon="fish" href="/full-fishing-bar/overview">
    **Problem it solves:** The fishing mini-game can feel punishing, especially for players who find it frustrating or inaccessible.

    Full Fishing Bar lets you set the bobber bar size to fill the entire catch zone, making every catch a guaranteed success. An optional auto-hook setting can hook fish for you automatically so you skip the mini-game entirely.

    Download: [Nexus Mods](https://www.nexusmods.com/stardewvalley/mods/23006) · [CurseForge](https://www.curseforge.com/stardewvalley/mods/full-fishing-bar)
  </Card>
</CardGroup>

## Requirements

All mods in this collection share the same base requirements:

- **Stardew Valley 1.6 or later** — earlier versions are not supported.
- **SMAPI** — the Stardew Modding API, available at [smapi.io](https://smapi.io). SMAPI is the mod loader that makes all of these mods possible.

Installing **Generic Mod Config Menu (GMCM)** is optional but highly recommended. It adds an in-game configuration UI so you can adjust mod settings without editing JSON files. See [Mod Integrations](/compatibility/mod-integrations) for more detail.
